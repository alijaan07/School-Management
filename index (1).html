Backup & School Settings

This version stores records in this browser on this computer. Export backups regularly. Clearing browser data can erase records. Use the same browser/device or import a backup to restore data.

For a multi-user school-wide system, central database, logins, and access from multiple computers, this prototype would need a hosted backend.

Admin Security

Only share your password with trusted staff. This lock applies to this browser profile and this HTML file.

Security limitation: because this is a standalone offline HTML file, a technically skilled person with access to the file can bypass its lock. For stronger protection, use a Windows account password and keep the file in your private Windows user folder.
